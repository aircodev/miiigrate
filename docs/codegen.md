# Codegen: TypeScript type mapping

`migrate::codegen` writes one `export interface` per table plus an aggregate
`Database` type. The types describe values **as they arrive through
`database::query`** — that is, after JSON serialization. Types JSON cannot
carry (`Date`, `Buffer`) are never emitted.

## Mapping

| Database type | TypeScript | Why |
|---|---|---|
| `int2`, `int4`, `float4`, `float8` | `number` | Fits in a JSON number |
| `int8`, `numeric` | `string` | Loss-free — a JSON number cannot hold every 64-bit int or arbitrary-precision decimal |
| `timestamp`, `timestamptz`, `date` | `string` | RFC 3339 on the wire |
| `bytea`, `BLOB` | `string` | base64 on the wire |
| `json`, `jsonb` | `Json` (emitted alias) | Arbitrary JSON |
| Postgres enum | Label union, e.g. `export type Mood = 'happy' \| 'sad'` | |
| Array types | `T[]` | |
| Nullable column | `T \| null` | |

The `_iii_migrations` tracking table is excluded from the output.

## Introspection sources

- **Postgres** — `information_schema` and `pg_catalog` via
  `database::query`; full support including enums and arrays.
- **SQLite** — `pragma_table_info` via `database::query`; basic support
  (SQLite's dynamic typing maps through its declared type affinities).

## Example output

```typescript
// generated by miiigrate (dialect: postgres) — do not edit
export type Json = /* … */;
export type Mood = 'happy' | 'sad';

export interface Users {
  id: string;              // int8 -> loss-free string
  name: string;
  mood: Mood | null;
  created_at: string;      // timestamptz -> RFC 3339 string
}

export interface Database {
  users: Users;
}
```

## Workflow

Regenerate after every applied migration and commit the result together with
the migration file:

```sh
iii trigger migrate::up --json '{}'
iii trigger migrate::codegen --json '{}'
```

The output path is the configured `types_out`, or the `out` field of the
payload for a one-off override.
